# PPT 自动化组装工作台

> 基于 Markdown 模板与提示词，批量生成与组装演示文稿（PPT）。

## 功能

- `PPT组装工作台/assemble.py` — PPT 组装主脚本
- 各专题模块通过 `build.py` + prompts 驱动生成
- 配套讲稿与 PPT 制作规范文档

## 目录

| 目录 | 说明 |
|------|------|
| `PPT组装工作台/` | 通用组装工具 |
| `京津冀平台ppt/` | 京津冀平台各专题 PPT |
| `PPT制作规范.md` | 制作规范 |

## 技术栈

Python（python-pptx 等），Markdown → PPT 自动化流水线。
